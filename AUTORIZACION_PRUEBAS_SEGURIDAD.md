# Alcance de autorización para pruebas de seguridad

Este documento registra el alcance de las pruebas que el propietario de este proyecto autoriza realizar en sus propios archivos y entornos locales. No constituye autorización de OpenCode, sus proveedores, ni de ningún tercero.

## Pruebas permitidas

- Revisar estáticamente el código y la configuración de este proyecto.
- Ejecutar pruebas locales sobre componentes propios o entornos de prueba aislados.
- Documentar hallazgos reproducibles y proponer correcciones defensivas.
- Verificar que las correcciones no expongan archivos, credenciales ni datos personales.

## Límites

Esta autorización no permite acceder, interferir ni intentar eludir controles de servicios de terceros. En particular, quedan fuera de alcance:

- Evadir límites de uso, cuotas, bloqueos temporales o controles de acceso de OpenCode.
- Obtener tokens o uso ilimitado mediante cuentas, sesiones, redes o identidades nuevas.
- Ocultar o falsificar la identidad del dispositivo o automatizar la rotación de sesiones.
- Probar infraestructura ajena, extraer credenciales o afectar datos de otros usuarios.

Las pruebas deben detenerse si afectan servicios o datos fuera del entorno local autorizado. Los hallazgos deben comunicarse de forma responsable al mantenedor correspondiente.
